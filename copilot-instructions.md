# Copilot Instructions

## Design Guide

- Keep UI design playful, polished, and directly tied to the app's storytelling tone.
- Prefer readable layouts with clear hierarchy, generous spacing, and expressive headings.
- Use humorous or quirky language only when it enhances the user experience without reducing clarity.
- Maintain strong accessibility: use semantic markup, visible focus states, and screen-reader-friendly labels.
- Keep styling simple and maintainable: avoid overcomplicated animations or large external dependencies.
- Match the existing workshop workflow and brand voice, while letting the interface feel fresh and amusing.
- Preserve existing app behavior and routing; redesigns should be visual and UX-focused, not functional rewrites.
